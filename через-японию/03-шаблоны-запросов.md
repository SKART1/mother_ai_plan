# Шаблоны запросов для сезона «Мечта»

Как пользоваться: скопируйте запрос в чат, замените [квадратные скобки]. Все запросы мама со временем пишет сама — шаблоны нужны на старте.

## № 1. Классы достопримечательностей (урок 1)

```
Расскажи, какие виды достопримечательностей есть в Японии. На каждый вид —
2 предложения простыми словами: что это и чем впечатляет. Оформи списком.
```

## № 2. Места по классу (урок 2)

```
Назови 5 известных мест в Японии по теме: [ТЕМА, например «японские сады»].
Про каждое — короткий абзац: что это, чем вау, сколько времени там стоит
провести. Сначала самые известные.
```

## № 3. Место подробнее (домашки, урок 2)

```
Расскажи про [МЕСТО]: что там делать полдня, когда лучше приехать
(время дня и сезон), что посмотреть рядом. Простыми словами.
```

## № 4. Маршрут мечты (урок 3)

```
Составь черновик маршрута по Японии на [N] дней для женщины [возраст].
Ритм неспешный: 1–2 события в день, без ранних подъёмов.
[Города, если выбраны: например «Токио и Киото»].
Когда закончишь — спроси, что бы я хотела поменять.
```

## № 5. Правила этикета (урок 4)

```
Объясни правила этикета в Японии для туриста. Списком, каждое правило —
одна фраза плюс что будет, если случайно нарушить (по-доброму).
```

## № 6. Что попробовать (урок 4)

```
Посоветуй 10 блюд Японии для человека, который [НЕ ЕСТ, например «не ест
сырую рыбу и острое»]. Что попробовать в первую очередь, о каждом —
1–2 предложения. Отметь, что бывает «на улице», а что в ресторане.
```

## № 7. Картинка мечты (урок 5)

```
Нарисуй: [ОПИСАНИЕ, например «осенний сад в Киото, красные клёны,
мостик через пруд, утренний туман»].
```

Уточнения после: «сделай как акварель», «добавь солнце», «крупнее мостик».
Если картинка не получается — переформулировать один раз и не застревать.

## № 8. Путевая книга (урок 6)

```
Собери из моих заметок путевую книгу мечты: придумай заголовок, напиши
тёплое вступление на полстраницы, раздели на разделы по темам, к каждому
разделу — короткую подпись. Вот заметки:
[ВСТАВИТЬ ВСЕ СОХРАНЁННЫЕ АРТЕФАКТЫ: карта интересов, места, маршрут,
памятка]
```

## Правило на весь сезон (напоминание тренеру)

Цены, часы работы, правила визы и транспорта ИИ может подать неточно — уверенно. В сезоне «Мечта» это почти не страшно (мы ничего не покупаем), но привычка сверять важное с официальными сайтами закладывается на уроке 6 и станет железной в сезоне «Сборы».
